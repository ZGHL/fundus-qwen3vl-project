## 方向一 · 病灶感知阶段

### (1) 每个病灶的数据（精确值 + 数据集贡献；NV/IRMA 不可学）

v3 只训练 **MA / HE / EX / SE** 四个病灶，全部用真实专家 mask（无 RetSAM 弱标、无 grade 派生）。
下表为 **TRAIN** 的 present（阳性，来自真 mask）按数据集拆分：

| 病灶 | present 合计 | FGADR Seg-set | DDR lesion_seg | IDRiD seg | absent 合计 | absent 构成 |
|---|---:|---:|---:|---:|---:|---|
| MA | 1000 | 676 | 292 | 32 | 1300 | 硬负 FGADR 398 + DDR 175；干净负 grade-0 727 |
| HE | 1000 | 687 | 286 | 27 | 1300 | 硬负 FGADR 356 + DDR 143；干净负 grade-0 801 |
| EX | 1000 | 702 | 261 | 37 | 1300 | 硬负 FGADR 521 + DDR 252；干净负 grade-0 527 |
| SE |  860 | 599 | 227 | 34 | 1300 | **硬负 FGADR 913 + DDR 387；grade-0 干净负 = 0** |

> 注 1：**SE present 只有 860**，是因为全数据集真实 SE mask 阳性本就最少（用满）。
> 注 2：**SE 的 1300 个负样本全是"硬负"**（DR 图但 SE mask 为空，常含 EX/HE/反光 = 天然混淆物）——
> 负样本不缺、且质量高，但 v3 SE 特异度仍只有 0.397，说明 SE 过报是**视觉可分性**问题，不只是负样本数量问题。

**为什么 NV / IRMA 不可学（三条，缺一不可）：**

| 病灶 | 全数据集真 mask 阳性 | RetSAM 弱标 | 硬训后能力 | 结论 |
|---|---:|---|---|---|
| IRMA | 159 | 不产出 | F1 ≈ 0.33 | ❌ 不训 |
| NV | 49 | 不产出 | F1 ≈ 0.21 | ❌ 不训 |

1. **数据天花板**：IRMA 仅 159、NV 仅 49 张阳性；RetSAM 只产 HE/EX/SE，**连弱标都补不了**。
2. **视觉不可靠**：即便硬训，锁定评测 NV F1≈0.21 / IRMA F1≈0.33（分不清新生血管/IRMA 与正常或重叠血管）。
3. **处置**：v3 不训 NV/IRMA；下游 Stage-2 **永远 abstain、绝不当可见证据**（防臆造增殖性病变）。

## 方向二 · 零样本基模 vs 最优 v3（逐病灶 F1 等）

同一 1108 图像互斥测试集。基模用"公平 prompt"（给病灶名+视觉描述，只答 Present/Absent，宽松解析；
否则严格 JSON schema 下基模 ~74% 无法解析，测的是格式遵从而非感知）。

| 病灶 | base R | base Sp | base F1 | ‖ | v3 R | v3 Sp | v3 F1 | ‖ | v5 R | v5 Sp | v5 F1 |
|---|---:|---:|---:|---|---:|---:|---:|---|---:|---:|---:|
| MA | 0.042 | 0.962 | 0.077 | ‖ | 0.955 | 0.481 | 0.705 | ‖ |  |  |  |
| HE | 0.486 | 0.952 | 0.624 | ‖ | 0.706 | 0.810 | 0.706 | ‖ |  |  |  |
| EX | 0.560 | 0.946 | 0.671 | ‖ | 0.822 | 0.816 | 0.747 | ‖ |  |  |  |
| SE | 0.250 | 0.903 | 0.274 | ‖ | 0.950 | 0.397 | 0.344 | ‖ |  |  |  |
| **MACRO** | **0.335** | **0.941** | **0.411** | ‖ | **0.858** | **0.626** | **0.626** | ‖ |  |  |  |
| BalAcc | **0.638** | | | ‖ | **0.742** | | | ‖ |  | | |
| parse_fail | 0 | | | ‖ | 61 | | | ‖ |  | | |

**读法**：基模高特异度(0.94)是"几乎都说没有"换来的——MA 召回仅 4.2%、SE 25%、HE/EX 约一半。
v3 的贡献是把**召回从 0.335 拉到 0.858**（尤其 MA 0.042→0.955、SE 0.250→0.950）、macro F1 0.411→0.626、
BalAcc 0.638→0.742，代价是特异度 0.941→0.626（即把 MA/SE 推到过报一侧）。

> **v5 列待填**（数值你后续自己补）。v5 是逐病灶差异化再平衡，预期方向：**HE Recall↑**（修 referable 漏检）、
> **MA/SE Spec↑**（治过报，召回可降是预期 trade）、**EX 基本不变**。填表时注意 v5 用的是 3-way split：
> 逐病灶数应在 **TEST**（= v3 同款，可直接和上面 v3 列对比）上汇报，checkpoint 用 DEV 选定。
